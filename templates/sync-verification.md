# Sync verification receipt

- Scope: Approved files or note IDs
- Local revision: Commit identifier
- Remote revision: Independently observed matching identifier
- Destination: Device or deployed snapshot checked
- Content check: Expected managed paths and hashes, or the narrower inspection performed
- Conflicts: None found / listed and preserved
- Observed at: Timestamp and timezone
- Unverified: Destinations not accessible this session

## Evidence

Record the actual checks and results without including tokens or credentials.

## Limits

File counts alone do not verify content. A commit does not prove remote delivery. Remote delivery does not prove phone receipt. State the boundary that was actually checked.
