# Bounded context pack

Teaching template. Replace placeholders; do not include secrets or unrelated personal material.

- Pack ID: context-example-001
- Project ID: project-example
- Prepared: YYYY-MM-DD and timezone
- Based on revision: Exact source revision when available
- Purpose: One specific task
- Audience and access: Which tool receives this and what it can actually read

## Approved working rules

Include only the relevant current rules from the collaboration profile. They do not override the receiving service's policies or permissions.

## Current project state

Goal, constraints, accepted decisions, and unresolved choices. Link stable object IDs and sources.

## Essential evidence

Use short excerpts with source and location. Label facts, attributed claims, inferences, and disagreements. Mark anything stale.

## Task for this session

State the requested output, constraints, and acceptance check.

## Limits and omissions

List excluded material, unavailable attachments, external originals, and anything that did not fit. If essential context cannot fit, narrow the task or retrieve the source rather than silently dropping it.

## Return contract

Ask for the proposed result, supporting evidence, uncertainty, contradictions, suggested note updates, and open loops. No publication or unrelated edits are authorized by this pack.

## After review

Record accepted changes in the canonical notes and refresh the pack. Do not treat an old pack as the latest state.
