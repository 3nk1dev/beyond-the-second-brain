# Project handoff

- Project ID: project-example
- Updated: YYYY-MM-DD with timezone
- Revision: Commit or document revision

## Goal

The outcome we are working toward.

## Current state

What is actually true now, with evidence references.

## Changed this session

Accepted changes only.

## Decisions

Choice, reason, date, and source.

## Open loops

For each item: question, owner, next action, and blocker. Separate actionable work, user choices, external waits, and deferred scope.

## Next action

One concrete step.

## Do not do

Explicit exclusions and permission boundaries.

## Delivery

Verified destination, observation time, and remaining gaps.
